WAN

WiFi as WAN

Only these ports can be reached on the internet. Everything else — including anything trying to reach this bridge from the internet — is blocked. An entry is a port number, optionally suffixed /tcp or /udp; a bare number means TCP. The defaults cover NTRIP (2101, 2102) and RustDesk (21115–21117, including 21116/udp, which RustDesk does not work without).

This device has one radio. While the WAN is connected, the bridge’s own WiFi is forced onto the upstream network’s channel, and the channel set on the dashboard is ignored.

Saving a change to the network, password or the checkbox restarts the bridge. Every WiFi client will disconnect and rejoin. Changing only the port list takes effect immediately.
