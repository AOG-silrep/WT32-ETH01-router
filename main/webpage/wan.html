WAN

WiFi as WAN

Which ports a client may reach through this uplink is on the Port Whitelist page. It is set separately because it is the one WAN setting that takes effect without restarting the bridge.

This device has one radio. While the WAN is connected, the bridge’s own WiFi is forced onto the upstream network’s channel, and the channel set on the LAN page is ignored.

Saving a change to the network, password or the checkbox restarts the bridge. Every WiFi client will disconnect and rejoin.
